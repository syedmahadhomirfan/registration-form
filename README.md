Project Overview:
This project is a basic registration form built using HTML. It demonstrates how to collect user input through different types of form elements:

*Text fields for name, email, and phone number.
*Password field for secure input.
*Radio buttons for selecting gender.
*Dropdowns (select boxes) for date of birth (day, month, year).
*Checkboxes for multiple language selection.
*Textarea for address.
*Submit button to send the form data.

 The purpose of this project is to practice form creation in HTML and understand how different input types work. It’s a foundational exercise for building user registration systems, which can later be enhanced with CSS for styling and JavaScript/PHP for validation and backend integration.
